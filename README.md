## What it does
Routes Bridge is a Fabric 1.21.10 mod for Hypixel SkyBlock that provides dungeon information to the [RoutesMod](https://github.com/imnothaxing/RoutesMod) on the latest version.

## Setup
To install the mod, simply add it to your mods folder inside your `.minecraft` directory.

This mod requires the Fabric API mod to work, so you should install it too.

You also need the latest version of the [RoutesMod](https://github.com/imnothaxing/RoutesMod). Place the unzipped `routes` folder inside your mods folder. It is important that it is exactly in that location and with that name; otherwise, `/route` will not automatically update the overlay.

**IMPORTANT:** You do not need to install [ChatTriggers](https://chattriggers.com/), despite it being described in the RoutesMod installation guide. This mod replaces what ChatTriggers used to do on 1.8.

## How to use
Simply run `/route` when you want to see a video for your current room. You do not need to open anything in advance.
